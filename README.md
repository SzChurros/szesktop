# Szesktop

An minimalist DE based on i3wm and szcheme.

# Installation

## Devuan and Debian based distros

```sh
sudo apt update

sudo apt install \
i3-wm \
i3lock \
rofi \
dunst \
feh \
polybar \
ksnip \
network-manager-gnome \
fonts-jetbrains-mono \
xorg \
xinit \
x11-xserver-utils \
xclip \
picom \
rofimoji
```

## Artix and Arch based distros

```sh
sudo pacman -Syu \
i3-wm \
i3lock \
rofi \
rofimoji \
dunst \
feh \
polybar \
ksnip \
network-manager-applet \
ttf-jetbrains-mono \
xorg-server \
xorg-xinit \
xorg-xrandr \
xclip \
picom
```
